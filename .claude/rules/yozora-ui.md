# Yozora UI rules

- **Source of truth:** `design/tokens.json` and `design/yozora-*.css`. `app/static/css/yozora-*.css` and `tailwind.tokens.cjs`-style outputs are generated by `python -m design.tokens_tool build`; editing only a generated copy is reverted by the next build. `python -m design.tokens_tool check` must pass.
- **Tailwind is retired** (S9). `style.css` stays for the HTMX indicator and the Evidence drop-zone. Print templates under `app/templates/reports/` have their own CSS and are never restyled.
- **Lint:** every non-print template is linted by `tests/test_design_lint.py` (no hex colours, no `uppercase`, no arbitrary values, no numbered headings). The old allow-list is deleted; new templates must be added to `MIGRATED_TEMPLATES`.
- **Guards:** stale scope guards get add-only allowances in `tests/yozora_paths.py` (`YOZORA_S*_PATHS`); never delete or weaken a guard. Commit before the final suite run: three-dot guards only see commits.
- **Pixel gates:** serve mockups with `/static/` mapped to `app/static/`; harness `design/harness/gate_s*.py`. Content-driven or mockup-scaffold differences are recorded as exceptions, not fitted.
- **Global behaviour:** `app/static/js/app.js` (toasts via `X-Toast-Message`/`X-Toast-Type` headers, skeletons, failed-swap alerts, menus, modals). Server text goes in with `textContent`, never `innerHTML`.
- **Product rules:** one visible `.btn.primary` per state, never a disabled primary; framework names only where in scope; scores never combined across frameworks; the temporary `reviewer-name` inputs stay until Track 4.
