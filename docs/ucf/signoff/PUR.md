| UC-PUR-01 | **Processing within the consented purpose**<br>Each processing activity runs only for a purpose stated in the notice under which the data principal gave consent. Before a new use of existing data starts, such as a campaign, an analytics use or a data share, it is checked against the consented purposes, and it is blocked or fresh consent is sought if it falls outside them. This stops purpose creep. Proof is the processing record that links each activity to its purpose and the review records for new uses. | Data Protection Officer<br>critical | Sample processing activities such as a marketing campaign, an analytics use and a data share from the audit period. Trace each to a purpose in the notice under which consent was taken. Pass if every sampled activity maps to a consented purpose or to a recorded lawful ground. | Processing record or data inventory showing each activity and its purpose; consent notices and forms; records of new-use reviews; campaign or data-share approvals for the audit period. | DPDPA: s.4(1)-a (full) | Privacy-only. | [x] |
| UC-PUR-02 | **Processing without consent identified and documented**<br>Each case where personal data is processed without consent under a legitimate-use ground is identified, and a register names the specific ground relied on for each case. For each case relying on data the person volunteered, the register records the purpose and how a refusal by the person stops the use. The register is reviewed whenever processing changes, and any entry that rests on a ground the law does not recognize is removed. Proof is the register and its review records. | Data Protection Officer<br>high | Read the register and sample entries. Check each names a recognized legitimate-use ground and, for volunteered data, records the purpose and how refusal stops the use. Pass if every sampled entry has a valid named ground and none relies on an unrecognized ground such as general business interest. | Register of processing without consent with the ground named for each entry; records of how refusal stops voluntary-provision uses; register review records after processing changes; employment-purpose privacy notices. | DPDPA: s.4(1)-b (full); s.7 (full) | Privacy-only. Related to RSK-08 (records of processing); kept apart because the test is the lawful-ground record. | [x] |
| UC-PUR-03 | **Collection limited to what is necessary**<br>Each personal data field the organization collects is mapped to the stated purpose that needs it, and any field with no mapped purpose is removed or made optional. The check is repeated whenever a form, API or processing scope changes. This keeps collection to what is necessary. Proof is the field-to-purpose mapping and the change review records. | Data Governance Lead<br>high | Sample collection forms or API payloads. Compare each field with the mapping. Pass if every sampled field maps to a stated purpose and none is marked unnecessary or missing from the mapping. | Field-to-purpose mapping; sample collection forms and API schemas; review records for scope changes and for fields removed, for the audit period. | DPDPA: s.6(1) (full) | Privacy-only. Home for minimization. | [x] |
| UC-PUR-04 | **Accuracy of data used for decisions and disclosure**<br>The processing in which personal data is used to make a decision about a person or is disclosed to another party is identified. For that processing, checks for completeness, accuracy and consistency, such as validation at capture or reconciliation against the source, run before the data is used or disclosed. Flagged errors are corrected and the correction recorded. Proof is the list of covered processing and the data quality check records. | Data Governance Lead<br>medium | Obtain the list of covered processing and pick samples.
