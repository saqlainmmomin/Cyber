{# Shared behaviour for Yozora confirmation modals and small row actions. Registered once per document so boosted navigations do not stack listeners. - [data-modal-open="id"] shows the .scrim-modal with that id; [data-modal-close], the scrim itself and Escape hide it again. A modal form's own submit is the real HTMX request. - [data-copy-checksum] copies its value to the clipboard. - form[data-confirm-value] keeps its submit button disabled until the field named confirm_name equals the value exactly (typed-name confirmation; the server checks again). - tr[data-href] rows navigate on click; each row also carries a real link for keyboards. #}
